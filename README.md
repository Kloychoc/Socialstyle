# Payso Social Style

แบบทดสอบ Social Style 30 ข้อ พร้อมแผนที่ทีม สำหรับทีม Sales & Marketing

- `public/index.html` คือหน้าเว็บ มี 2 แท็บ ได้แก่แบบทดสอบและแผนที่ทีม
- `public/questions.js` เก็บคำถามและวิธีคิดคะแนน ใช้ร่วมกันทั้งหน้าเว็บและ server
- `server.js` คือ Express API (Vercel แปลงไฟล์นี้เป็น Function ให้อัตโนมัติ)
  - ใช้ Postgres เมื่อมีตัวแปร `DATABASE_URL`
  - ตอนรันในเครื่องโดยไม่มีตัวแปรนี้ จะเก็บข้อมูลเป็นไฟล์ `data/results.json` แทน

## Deploy บน Vercel

1. ไปที่ vercel.com แล้วกด **Add New → Project** จากนั้น Import repo **Socialstyle** และกด Deploy ได้เลยโดยไม่ต้องแก้ค่าใดๆ
2. เข้าโปรเจกต์ ไปแท็บ **Storage** แล้วสร้างฐานข้อมูล Postgres จาก Marketplace (เช่น **Neon**) และกดเชื่อมกับโปรเจกต์นี้ ระบบจะเพิ่ม `DATABASE_URL` ให้อัตโนมัติ
3. ไปที่ **Settings → Environment Variables** แล้วเพิ่ม `ACCESS_CODE` = รหัสทีม
   แนะนำให้ตั้งไว้ เพราะแผนที่ทีมแสดงชื่อคน ถ้าไม่ตั้ง ใครมีลิงก์ก็เข้าดูได้
4. ไปที่ **Deployments** แล้วกด **Redeploy** เพื่อให้ตัวแปรใหม่มีผล
5. เปิด `https://<ชื่อโปรเจกต์>.vercel.app/api/health`
   - ถ้าเห็น `"storage":"postgres"` แปลว่าพร้อมใช้งาน ส่งลิงก์หน้าแรกให้ทีมได้เลย
   - ถ้าเห็น `"storage":"none"` แปลว่ายังไม่ได้เชื่อมฐานข้อมูล ให้กลับไปทำข้อ 2

ตาราง `results` จะถูกสร้างให้อัตโนมัติตอนมีคนใช้งานครั้งแรก

## รันในเครื่อง

```bash
npm install
ACCESS_CODE=test npm start   # เปิด http://localhost:3000
```

## หมายเหตุ

- **การจำตัวตน:** แต่ละคนถูกจำด้วยรหัสที่เก็บไว้ในเบราว์เซอร์ ถ้าทำแบบทดสอบซ้ำในเบราว์เซอร์เดิม ระบบจะอัปเดตผลเดิม แต่ถ้าเปลี่ยนเครื่องหรือเปลี่ยนเบราว์เซอร์ ระบบจะนับเป็นคนใหม่
- **สิ่งที่ทีมเห็น:** คนอื่นเห็นได้แค่ชื่อ ทีม และสไตล์ ส่วนคำตอบรายข้อเก็บไว้ที่ server เท่านั้น
- **การลบผลที่ไม่ต้องการ:** เข้าไปที่ SQL editor ของ Neon แล้วรัน `DELETE FROM results WHERE name = 'ชื่อ';`
